## Projeto em destaque

### [Focadu](https://focadu.falveshub.com)

Plataforma de estudo gamificada que construo do zero, com trilhas de **Web Security** e **Linux**.
Sessões diárias com avaliação por voz via IA, laboratório de código e missões de terminal que rodam no navegador, e projetos semanais com prova pública de evolução.

Na prática, é também onde aplico o que estudo: a nota é sempre calculada no servidor, o gabarito nunca chega ao cliente antes da resposta, o uso de IA tem limites, o backup é automático e os repositórios dos alunos ficam privados.
